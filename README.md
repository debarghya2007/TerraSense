# TerraSense Smart Zoning Dashboard — Prototype

This is a standalone downloadable prototype based on the supplied TerraSense React frontend and FastAPI backend.

## Run
1. Unzip the folder.
2. Open `index.html` in a browser.
3. Use the input sliders/select and click **Calculate Irrigation Metrics**.
4. Use **Light / Dark / Colour** at the top-right to switch themes.

No Node.js, Python server, npm install, or internet connection is required for this prototype.

## Included
- TerraSense dashboard layout adapted from the supplied Frontend.txt
- Irrigation calculations adapted from the supplied Backend.py
- Three themes: Light, Dark, Colour
- Responsive layout
- Interactive sensor controls
- Zone water-flow chart
- Zone recommendation cards
- Theme preference persisted in browser local storage

The prototype intentionally runs the supplied calculation logic in-browser so it can be opened directly as a single HTML file.
